# Recursos de demostración
Estos WEBP son recortes de las maquetas adjuntas en esta conversación. Sirven para comparar composición, no son fotografías maestras ni activos finales del producto. No se han regenerado.

Sustituir por assets reales/validados del proyecto. La marca de la interfaz no debe imponerse a la marca del cliente. La imagen de cables no significa que Xending fabrique cables. No publicar logos ni textos dibujados por IA como identidad oficial.

El archivo demo-assets.ts los incluye como data URI para la vista HTML sin conexión. En producción usar el Storage/CDN existente y sus reglas. Ninguna fuente tipográfica está incluida.
