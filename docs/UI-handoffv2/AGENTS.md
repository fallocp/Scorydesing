Leer README.md, docs/PLAN_DE_FLUJO_VIGENTE.md, docs/DISENO_MAESTRO.md y docs/PROMPT_CODEX.md. Respetar las instrucciones del repositorio anfitrión; no reemplazar su AGENTS.md.

La revisión actual no autoriza implementar toda la aplicación. Por defecto: inspección y plan. Solo ejecutar una vista después de aprobación expresa.

No usar legacy/demo-v1 como especificación vigente. No copiar su package.json, router, controlador local, datos ficticios ni motor de preview a producción.

Conservar Studio actual con ambos bancos de copys; News y Daily separados. Crear y editar recibe la nueva UI. Reutilizar servicios, prompts, editores, montaje, versiones y exports actuales.

No inventar capacidades, dimensiones, estilos, logos, metadatos, aprobaciones ni guardados. Registrar conexiones nuevas como pendientes de integración. No acceder o escribir en la Biblioteca de ScoryDesign sin una conexión autorizada y comprobada.
