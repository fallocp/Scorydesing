# Xending — Banco de copies de velocidad para pagos internacionales

## Objetivo editorial

Comunicar que Xending ayuda a realizar pagos internacionales con mayor velocidad, seguimiento y acompañamiento hacia Estados Unidos, Europa, Asia y otros mercados, sin utilizar mensajes exagerados ni CTA ambiguos.

## Criterios de tono

- Tensión moderada, basada en situaciones reales.
- El beneficio de Xending debe aparecer en el subline.
- Evitar mensajes que únicamente le pidan al cliente organizarse.
- Evitar CTA como “activa tu pago”, “conoce la ruta”, “cotiza tu ruta” o “conoce tus opciones”.
- No prometer mismo día para todos los países o todas las operaciones.
- Cuando aplique, invitar a consultar si el pago puede completarse el mismo día.
